Frequently asked questions

The questions our support team hears most.

How accurate is LookAI's object detection?

Our models achieve 98%+ mAP on standard benchmarks across 1,000+ object categories. Accuracy depends on image quality, lighting, and occlusion — but we consistently outperform generic models on real-world data.

What image formats do you support?

We support JPEG, PNG, WebP, GIF, BMP, and TIFF. Video streams are supported via RTSP, MJPEG, and direct file upload (MP4, MOV, AVI). Maximum image size is 20MB; video up to 500MB.

Can I use LookAI on-device?

Yes. Our edge-optimized models run on iOS, Android, and Linux devices with as little as 500MB RAM. You can also use our cloud API for heavier workloads. Many customers use a hybrid approach.

Is there a free tier?

Absolutely. The Starter plan is free forever with 100 API calls per day. No credit card required. Upgrade to Pro when you need more capacity or advanced features.
